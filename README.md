# 하루 플래너 웹 앱

월간 달력, 날짜별 시간 일정, 완료 표시, 일정별 알림을 제공하는 설치형 웹 앱입니다. 별도 빌드 명령 없이 정적 파일만으로 실행됩니다.

## GitHub 저장소에 올리기

1. ZIP 파일을 압축 해제합니다.
2. 압축 해제 폴더 안의 모든 파일을 Planner 저장소 최상위에 올립니다. 이전 Windows용 파일을 교체하는 경우 오래된 실행 파일도 저장소에서 제거하고, Dockerfile이 최상위에 있는지 확인합니다.
3. GitHub에 커밋하고 기존 Docker 배포를 다시 실행합니다.

Docker 배포 서비스는 저장소 최상위의 Dockerfile을 사용합니다. 빌드 명령과 시작 명령은 비워두면 됩니다. Dockerfile은 nginx로 정적 파일을 제공합니다.

정적 사이트 배포를 선택할 수 있는 호스트라면 빌드 명령은 비우고, 게시 폴더를 저장소 루트 디렉터리로 지정하면 됩니다.

## 웹 앱 설치

배포된 HTTPS 주소를 Edge에서 열고 브라우저 메뉴의 앱 설치 기능을 선택하면 별도 창으로 실행할 수 있습니다. 앱 설치 버튼은 브라우저가 설치 가능한 상태라고 알릴 때 표시됩니다.

## 알림과 데이터

- 일정과 알림 설정은 사용 중인 브라우저의 로컬 저장소에 보관됩니다. 다른 브라우저나 기기와 자동 동기화되지는 않습니다.
- 소리 없는 화면 알림은 플래너 웹 앱이 열려 있을 때 표시됩니다. 앱을 완전히 닫으면 알림이 실행되지 않습니다.
- 달력 위쪽 알림 버튼으로 전체 알림을 켜거나 끌 수 있습니다. 각 일정에서도 개별로 알림을 설정할 수 있습니다.
- 알림 창에서 완료, 10분 미루기, 전체 알림 끄기를 선택할 수 있습니다.
- 오프라인 캐시는 앱 화면과 정적 파일을 저장합니다. 브라우저 저장소를 지우면 일정 데이터도 삭제될 수 있습니다.
